จาก Error Log ที่คุณส่งมา มีปัญหาหลัก ๆ 2 กลุ่มที่ต้องแก้ไข:

1. **Missing Provider สำหรับ `TranslateService`** และ **Missing Pipe `translate`** (เกิดจากไม่มีการติดตั้ง `@ngx-translate/core` อย่างถูกต้องในโมดูลทดสอบ)
2. **Template Syntax Errors** (HTML ที่เขียนผิดพลาด)

เราจะแก้ไขทีละส่วนครับ

---

## 1. แก้ไขปัญหา Missing Provider & Pipe

### 1.1 ติดตั้ง Dependencies ที่จำเป็น
ตรวจสอบให้แน่ใจว่าคุณได้ติดตั้ง `@ngx-translate/core` และ `@ngx-translate/http-loader` แล้ว:

```bash
npm install @ngx-translate/core @ngx-translate/http-loader --save
```

### 1.2 ตั้งค่า TranslateModule ใน Root Module หรือ AppConfig
ถ้าใช้ Standalone Components ต้อง import `TranslateModule` หรือ `provideTranslateService` ใน `app.config.ts`:

```typescript
// app.config.ts
import { ApplicationConfig, importProvidersFrom } from '@angular/core';
import { provideHttpClient } from '@angular/common/http';
import { TranslateModule, TranslateLoader } from '@ngx-translate/core';
import { TranslateHttpLoader } from '@ngx-translate/http-loader';
import { HttpClient } from '@angular/common/http';

export function HttpLoaderFactory(http: HttpClient) {
  return new TranslateHttpLoader(http, './assets/i18n/', '.json');
}

export const appConfig: ApplicationConfig = {
  providers: [
    provideHttpClient(),
    importProvidersFrom(
      TranslateModule.forRoot({
        defaultLanguage: 'th',
        loader: {
          provide: TranslateLoader,
          useFactory: HttpLoaderFactory,
          deps: [HttpClient]
        }
      })
    )
  ]
};
```

### 1.3 แก้ไข Test Specs (ไฟล์ .spec.ts)
**ทุก Component** ที่ใช้ `TranslateService` หรือ `TranslatePipe` ใน Template ต้อง **import `TranslateModule` ใน TestBed** หรือใช้ `TranslateTestingModule` ที่เราสร้างเอง

**วิธีที่ 1: ใช้ `TranslateModule.forRoot()` ใน TestBed**

```typescript
// ตัวอย่าง job-list.component.spec.ts
import { ComponentFixture, TestBed } from '@angular/core/testing';
import { JobListComponent } from './job-list.component';
import { TranslateModule } from '@ngx-translate/core';
import { HttpClientTestingModule } from '@angular/common/http/testing';

describe('JobListComponent', () => {
  let component: JobListComponent;
  let fixture: ComponentFixture<JobListComponent>;

  beforeEach(async () => {
    await TestBed.configureTestingModule({
      imports: [
        JobListComponent, // Standalone
        HttpClientTestingModule,
        TranslateModule.forRoot() // ✅ จำเป็น
      ]
    }).compileComponents();

    fixture = TestBed.createComponent(JobListComponent);
    component = fixture.componentInstance;
    fixture.detectChanges();
  });

  it('should create', () => {
    expect(component).toBeTruthy();
  });
});
```

**วิธีที่ 2: สร้าง `TranslateTestingModule` (แนะนำ)**
สร้าง `TranslateTestingModule` เพื่อลดการทำซ้ำ:

```typescript
// shared/testing/translate-testing.module.ts
import { NgModule } from '@angular/core';
import { TranslateModule, TranslateLoader, TranslateService } from '@ngx-translate/core';
import { of } from 'rxjs';

class FakeLoader implements TranslateLoader {
  getTranslation(lang: string) {
    return of({}); // return empty translations
  }
}

@NgModule({
  imports: [
    TranslateModule.forRoot({
      loader: { provide: TranslateLoader, useClass: FakeLoader },
      defaultLanguage: 'en'
    })
  ],
  exports: [TranslateModule]
})
export class TranslateTestingModule {}
```

จากนั้น import ในทุก spec:

```typescript
import { TranslateTestingModule } from '@shared/testing/translate-testing.module';

beforeEach(async () => {
  await TestBed.configureTestingModule({
    imports: [
      JobListComponent,
      TranslateTestingModule // ✅ ใช้ module ที่เตรียมไว้
    ]
  }).compileComponents();
});
```

### 1.4 แก้ไข TranslatePipe Spec
Error ที่ `TranslatePipe > should return the same value (placeholder)` เกิดจากการใช้ `new TranslatePipe()` โดยตรง ซึ่งต้อง inject service ใน TestBed

**แก้ไข `translate.pipe.spec.ts`:**

```typescript
import { TranslatePipe } from './translate.pipe';
import { TestBed } from '@angular/core/testing';
import { TranslateService } from '@ngx-translate/core';
import { TranslateTestingModule } from '@shared/testing/translate-testing.module';

describe('TranslatePipe', () => {
  let pipe: TranslatePipe;

  beforeEach(() => {
    TestBed.configureTestingModule({
      imports: [TranslateTestingModule]
    });
    // inject service จาก TestBed
    const translateService = TestBed.inject(TranslateService);
    pipe = new TranslatePipe(translateService);
  });

  it('should return the same value (placeholder)', () => {
    expect(pipe.transform('test')).toBe('test'); // หรือตาม logic
  });
});
```

## 2. แก้ไข Template Syntax Errors

### 2.1 QuotationDetailComponent
Error: `Unexpected closing tag "i"` และ `Unexpected closing tag "button"`

สาเหตุ: ใช้ `<i-tabler>` แต่ปิดด้วย `</i>` และ `</button>` ผิดตำแหน่ง

**แก้ไขไฟล์ `quotation-detail.component.html` บรรทัดที่มีปัญหา:**

จาก:
```html
<div class="card-body d-flex gap-2">
  <button class="btn btn-success"><i-tabler name="check" class="icon"></i> อนุมัติ</button>
  <button class="btn btn-outline-danger"><i-tabler name="x" class="icon"></i> ปฏิเสธ</button>
</div>
```

เป็น:
```html
<div class="card-body d-flex gap-2">
  <button class="btn btn-success">
    <i-tabler name="check" class="icon"></i-tabler> อนุมัติ
  </button>
  <button class="btn btn-outline-danger">
    <i-tabler name="x" class="icon"></i-tabler> ปฏิเสธ
  </button>
</div>
```

**หมายเหตุ:** `i-tabler` เป็น Custom Component ต้องปิดด้วย `</i-tabler>` เสมอ ไม่ใช่ `</i>`

### 2.2 OrderDetailComponent
Error: `Parser Error: Unexpected token 'wos'` ใน `[class.bg-yellow]="order.status === '{{ 'wos.statusPending' | translate }}'"`

**สาเหตุ:** คุณใช้ interpolation `{{ }}` ซ้อนกันใน Property Binding ซึ่งผิด语法

**แก้ไข:**
เปลี่ยนจาก:
```html
<span class="badge" 
  [class.bg-yellow]="order.status === '{{ 'wos.statusPending' | translate }}'"
  [class.bg-blue]="order.status === '{{ 'wos.statusShipping' | translate }}'"
  [class.bg-green]="order.status === '{{ 'wos.statusDelivered' | translate }}'"
  [class.bg-red]="order.status === '{{ 'wos.statusCancelled' | translate }}'">
  {{ order.status }}
</span>
```

เป็น:
```html
<span class="badge" 
  [class.bg-yellow]="order.status === ('wos.statusPending' | translate)"
  [class.bg-blue]="order.status === ('wos.statusShipping' | translate)"
  [class.bg-green]="order.status === ('wos.statusDelivered' | translate)"
  [class.bg-red]="order.status === ('wos.statusCancelled' | translate)">
  {{ order.status }}
</span>
```

**หรือ** ใช้ method ใน Component แทน:

```typescript
// order-detail.component.ts
getStatusClass(status: string): string {
  const map: Record<string, string> = {
    pending: 'bg-yellow',
    shipping: 'bg-blue',
    delivered: 'bg-green',
    cancelled: 'bg-red'
  };
  return map[status] || 'bg-secondary';
}
```

แล้วใน Template:
```html
<span class="badge" [class]="getStatusClass(order.status)">{{ order.status }}</span>
```

### 2.3 QuotationCreateComponent
Error: `The pipe 'number' could not be found`

**สาเหตุ:** `number` pipe มาจาก `CommonModule` แต่ยังไม่ได้ import ใน Standalone Component

**แก้ไข:** ใน `quotation-create.component.ts` ให้ import `CommonModule`:

```typescript
import { CommonModule } from '@angular/common';

@Component({
  standalone: true,
  imports: [CommonModule, ...], // ✅ เพิ่ม CommonModule
  ...
})
```

## 3. ตรวจสอบการ Import `TranslateModule` ในทุก Standalone Component
ถ้า Component ใช้ `translate` pipe ใน template ต้อง import `TranslateModule` ใน `imports` ด้วย:

```typescript
import { TranslateModule } from '@ngx-translate/core';

@Component({
  standalone: true,
  imports: [CommonModule, TranslateModule, ...], // ✅
  ...
})
export class HeaderComponent { ... }
```

**ซึ่งจะต้องทำกับทุก Component ที่ใช้ translate pipe** (Header, Sidebar, Footer, และอื่น ๆ)

---

## 4. สรุปขั้นตอนการแก้ไขทั้งหมด

| ปัญหา | วิธีแก้ไข |
|--------|-----------|
| `No provider for TranslateService` | import `TranslateModule.forRoot()` หรือ `TranslateTestingModule` ใน TestBed |
| `The pipe 'translate' could not be found` | import `TranslateModule` ใน `imports` ของ Component และใน TestBed |
| `The pipe 'number' could not be found` | import `CommonModule` ใน Component |
| `Unexpected closing tag "i"` | เปลี่ยน `</i>` เป็น `</i-tabler>` |
| `Parser Error: Unexpected token` | อย่าใช้ `{{ }}` ซ้อนใน property binding ใช้ `( )` หรือ method |
| `inject() must be called from injection context` | ใช้ TestBed เพื่อสร้าง TranslatePipe |

## 5. คำแนะนำเพิ่มเติม: สร้าง Base Test Setup

เพื่อลดการทำซ้ำ ให้สร้างไฟล์ `test-setup.ts` หรือ `testing-utils.ts`:

```typescript
// testing-utils.ts
import { TranslateModule, TranslateLoader } from '@ngx-translate/core';
import { of } from 'rxjs';

export const getTranslateTestingModule = () => {
  return TranslateModule.forRoot({
    loader: {
      provide: TranslateLoader,
      useValue: {
        getTranslation: (lang: string) => of({})
      }
    }
  });
};
```

แล้วในทุก spec ใช้:

```typescript
import { getTranslateTestingModule } from '@testing-utils';

TestBed.configureTestingModule({
  imports: [MyComponent, getTranslateTestingModule()]
});
```
